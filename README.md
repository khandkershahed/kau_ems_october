# EMS App KAU (Employee Management System)

This application is an Employee and Payroll Management System. Below is a summary of the current features and modules supported by the application:

| Feature Category | Description |
| --- | --- |
| **Employee Management** | Manage employee profiles, service history, and user categories. |
| **Payroll Setup** | Configure pay scales, pay grades, payroll groups, and dynamic payroll components. |
| **Salary Management** | Setup, calculate, review, and generate salary bills (supports single & bulk operations). |
| **Bonus Management** | Setup bonus groups/components, calculate estimates, review, and generate bonus bills. |
| **General Provident Fund (GPF)** | Track active/past contributions, view user ledgers, manage comments, and process settlements. |
| **Office Management** | Manage organizational structure including department offices. |
| **Reporting & Archives** | Generate salary reports, blank forms, and upload/preview archived salary records. |
| **System & Security** | Secure user authentication, profile management, and dashboard overviews. |
